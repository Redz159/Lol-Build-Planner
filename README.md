# LoL Build Planner

A personal League of Legends build planner: save rune pages and item builds per champion, entirely client-side (no backend, no account). Data lives in your browser's local storage; builds can be exported/imported as JSON files to share.

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys automatically to GitHub Pages via `.github/workflows/deploy.yml` on push to `main`.
